# Voting System

A Java Swing-based desktop application for managing votes, candidates, and elections. This project is built as an **Apache NetBeans Ant** project and uses local text files for data storage.

## Prerequisites

To run and build this project, you will need:

* **Java Development Kit (JDK):** Version 11 or higher (JDK 17 recommended)
* **IDE:** [Apache NetBeans](https://netbeans.apache.org/)
* **Apache Ant:** (Included with NetBeans)
* **Git & GitHub:** For version control and collaboration

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nerfeguno/VotingSystem.git
   cd VotingSystem
   ```

2. **Open in NetBeans:**
   * Launch Apache NetBeans.
   * Go to `File` → `Open Project` and select the cloned `VotingSystem` directory.

3. **Run the Application:**
   * Right-click the project in NetBeans and select **Run** (or press `F6`).

## Building from the Command Line

You can build the project artifact (.jar) using Ant directly from your terminal:

```bash
ant clean jar
```

Upon a successful build, the executable JAR file will be located in the `dist/` directory.

## Data Storage & Security

This application uses local text files for its database, managed by the `DataManager` class. The files are stored in the `data/` directory:
* `users.txt`
* `candidates.txt`
* `votes.txt`

**⚠️ IMPORTANT:** Do **NOT** commit real voter information, passwords, or production voting data to this repository. Use only sample data for development. Ensure that `/data/users.txt` and `/data/votes.txt` remain in your `.gitignore` file.
